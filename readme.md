# Programación II - Mayte Rochina

Repositorio destinado a la organización, desarrollo y gestión de los proyectos de la asignatura. Aquí se abordan tecnologías basadas en el ecosistema de Python, abarcando desde bases de programación hasta el desarrollo web y de sistemas empresariales.

---

## 🛠️ Tecnologías Principales

### 1. Python
Es un lenguaje de programación de alto nivel, interpretado y de propósito general. Es conocido por su sintaxis clara y legible, lo que facilita el aprendizaje y el desarrollo rápido de software. En este repositorio sirve como el núcleo lógico para la ejecución de scripts, algoritmos y la base para frameworks más avanzados.

### 2. Django
Es un framework de desarrollo web de alto nivel para Python que fomenta el desarrollo rápido y un diseño limpio y pragmático. Sigue el patrón arquitectónico MVT (Modelo-Vista-Template) y viene con una gran cantidad de herramientas integradas (como panel de administración, autenticación y ORM) para construir aplicaciones web robustas y seguras.

### 3. Odoo
Es un sistema ERP (Planificación de Recursos Empresariales) de código abierto desarrollado en Python. Permite gestionar de manera integral los procesos de negocio de una organización (ventas, inventario, contabilidad, recursos humanos, entre otros) a través de módulos interconectados y una arquitectura basada en modelos ORM propios y vistas XML.

## 📁 Estructura del Repositorio

El repositorio está organizado en carpetas y subcarpetas para separar los diferentes proyectos y prácticas de clase:

* `/python` - Scripts, ejercicios y fundamentos del lenguaje.
* `/django` - Proyectos y aplicaciones web desarrolladas con el framework Django.
* `/odoo` - Módulos personalizados y configuraciones para entornos Odoo.

Para mantener limpio el repositorio, se utiliza un archivo `.gitignore` global que excluye entornos virtuales, archivos compilados y bases de datos locales.
